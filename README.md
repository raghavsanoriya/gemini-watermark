# GemClean

A responsive, browser-first single-page tool for repairing the visible lower-right Gemini image mark on images you own or are authorized to edit.

## Local development

```bash
npm install
npm run dev
```

## Deployment

Pushing to `main` runs the GitHub Pages workflow. Once Pages is enabled for this repository, the website is available at:

`https://raghavsanoriya.github.io/gemini-watermark/`
